# NLP Data Query Application

This application allows users to upload datasets (CSV, Excel, JSON) and query them using natural language via text or voice input. It also automatically generates charts when applicable.

## Features
- Dataset upload
- Natural language querying
- Voice-based querying
- Automatic chart generation

## Tech Stack
- Python
- Streamlit
- Pandas
- Plotly
- SpeechRecognition

## Deployment
Deployed using Streamlit Cloud.
